## PlayStation 2 Storage & Network Suite

A complete three-part desktop toolkit engineered to initialize, manage, and load PlayStation 2 internal hard drives (up to **2 TB**) safely and effortlessly:

| Project | Purpose | Key Highlights |
| :--- | :--- | :--- |
| **[PS2 HDD CREATOR](https://github.com)** | **2 TB Drive Initializer** | 1-click disk wipe, FreeHDBoot image writer, and `+OPL` partition setup with strict USB-only drive protection. |
| **[PS2 HDD MOUNTER](https://github.com)** | **PFS Partition & File Explorer** | Browse APA partitions, create/delete partitions safely, and transfer `.VCD`, `.ELF`, and OPL assets over USB. |
| **[PS2FTPCONNECTOR](https://github.com)** | **Network Multi-ISO Batch Injector** | High-speed TCP/IP game streaming, Mode 1–8 editor, ISO backup ripper, and remote console power-off (`HDLGameInstaller`). |
